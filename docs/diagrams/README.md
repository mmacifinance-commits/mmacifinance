# System Diagrams — Budget Fund Utilization & Tracking

All diagrams are written in **Mermaid** syntax inside Markdown files.

## How to render

| Tool | How |
|---|---|
| **VS Code** | Install [Mermaid Preview](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid) extension, then open any `.md` file and use *Markdown Preview* |
| **GitHub** | Push to GitHub — diagrams render automatically in any `.md` file |
| **Online** | Paste the code block content into [mermaid.live](https://mermaid.live) |
| **Export image** | Use [mermaid.live](https://mermaid.live) → download as PNG/SVG |
